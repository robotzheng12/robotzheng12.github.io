途径 操作步骤

日志中查找 抓取实时日志，日志中一般能找到包名及进程号

3.2 看不到应用日志？

可能原因及解决方案：

  1. 检查代码调用：确认代码中是否正确调用了 hilog 接口
  2. 检查连接授权：确保 HDC 连接正常，设备已授权调试
  3. 系统隔离限制：某些应用（如”卓易通”）因系统隔离，其日志可能无法被 hilog 捕获

3.3 hilog 命令的日志级别受限

快捷命令速查

命令 功能
hdc -v 查看 HDC 版本
hdc list targets 列出已连接设备
hdc shell 进入设备 shell

hdc file recv <remote> <local> 从设备拉取文件
hdc bugreport 生成完整故障报告
