二、安装与连接调试

2.1 安装步骤

  1. 解压安装：建议解压到根目录，如 D:\android-platform-tools
  2. 添加环境变量：将 platform-tools 目录添加到系统 PATH
  3. 验证安装：执行以下命令检查

2.2 手机开启 USB 调试模式

  1. 进入「设置」→「关于手机」，连续点击「版本号」7 次，直到出现”您现在处于开发者模式”的提示
  2. 返回「设置」→「开发者选项」，开启「USB 调试」
  3. 使用 USB 数据线连接手机与电脑
  4. 手机上会弹出”允许 USB 调试吗？”的授权框，点击「确定」

2.3 验证连接

若看到设备列表中显示 device 状态，则连接成功。

快捷命令速查

命令 功能
adb version 查看 ADB 版本
adb devices 列出已连接设备
adb shell 进入设备 shell
adb logcat -c 清除日志缓存
adb logcat *:E 只显示错误级别日志
adb logcat -b crash 抓取崩溃日志
adb logcat -d 导出当前日志缓冲区

日志级别说明

级别 缩写 说明
Verbose V 详细日志
Debug D 调试信息
Info I 一般信息
Warn W 警告信息
Error E 错误信息
Fatal F 致命错误
Silent S 静默（屏蔽所有输出）
