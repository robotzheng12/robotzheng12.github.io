Created2026-05-05|Updated2026-05-05|技术教程

Hermes Agent 是由 Nous Research 开发的开源自主 AI 智能体，具备持久记忆、自改进学习能力和 40+ 内置工具，支持 CLI 及 Telegram、Discord、飞书、微信等 15+ 平台接入。本文档旨在帮助您快速完成安装部署并掌握日常使用方法。

一、简介

1.1 什么是 Hermes Agent？

Hermes Agent（项目标志 ☤）是开源自主 AI 智能体框架，遵循 MIT 协议。与普通聊天机器人不同，它是一个能持久运行、跨会话保留记忆、并从每次任务中学习改进的 AI 系统。核心能力包括：

  • 自改进学习循环：完成任务后自动提炼流程生成可复用技能
  • 持久化记忆：通过 MEMORY.md、USER.md 跨会话保存用户偏好与上下文
  • 多工具调用：内置 40+ 工具，支持终端执行、文件读写、浏览器自动化等
  • 多平台接入：统一网关接入 Telegram、Discord、飞书、微信等主流平台

1.2 系统要求

注意：Hermes Agent 要求大模型的上下文窗口至少为 64K，以维持足够的工作记忆。

5.1 本地部署

5.3 云服务器部署

  • 阿里云轻量应用服务器：选择 Hermes Agent 应用镜像，规格推荐 2 核 4G 以上
  • AWS EC2：支持 Amazon Linux 2023，需配置 IAM Role 调用 Bedrock 模型权限
  • 阿里云计算巢：一键部署，自动完成资源编排和环境初始化
  • 无影云电脑：预装 Hermes Agent，开箱即用

5.4 其他环境

  • QNAP NAS：通过 Container Station 使用 Docker Compose 部署
  • Android Termux：在 Termux 环境中运行一键安装命令

六、安全与故障排查

6.1 安全建议

  • 隔离运行：推荐使用 Docker 沙箱环境运行 Hermes Agent，将执行环境与宿主机隔离
  • 访问控制：避免将服务端口直接暴露在公网，如需远程访问请使用 VPN 或 IP 白名单
  • 凭证保护：妥善保管 API Key 和令牌，泄露后及时更换
  • 技能来源：仅从可信来源安装扩展或技能

6.2 常见问题排查

问题 解决方案
安装失败 检查网络连接，确保 Python 3.10+ 已安装
模型调用失败 验证 API Key 正确性，检查网络代理设置
工具执行异常 使用 hermes tools 检查工具状态
配置文件丢失 重新运行 hermes setup 初始化配置

  • 仪表盘：运行 hermes dashboard 可查看 Token 用量统计和中文界面
