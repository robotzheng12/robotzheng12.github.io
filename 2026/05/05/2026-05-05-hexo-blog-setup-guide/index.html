🔌 进阶：常用插件推荐

插件 功能

hexo-lazyload-image 图片懒加载，提升页面加载速度
hexo-offline 开启 Service Worker，支持离线访问
hexo-admonition 在文章中插入漂亮的提示框（Note、Warning 等）
hexo-gallery 以优雅的瀑布流形式展示图片

💡 避坑指南

问题一：安装 hexo-cli 工具后，执行 hexo 报错

解决方案：

  1. 找到 npm 全局安装路径，执行命令：

    它会输出一个路径，例如 C:\Users\Administrator\AppData\Roaming\npm

  2. 把这个路径添加到系统环境变量：

    • 右键「此电脑」→「属性」→「高级系统设置」→「环境变量」
    • 在「系统变量」或「用户变量」中找到 Path，双击编辑
    • 点击「新建」，粘贴上面得到的路径
    • 确定保存后，重新打开命令行窗口，再试 hexo 命令
