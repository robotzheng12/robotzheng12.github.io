Trae AI 命令白名单配置指南

Created2026-05-08|Updated2026-05-08|技术教程
|Post Views:

Trae AI 的命令白名单可以通过设置界面或修改配置文件进行修改。Trae AI 提供了两种主要的配置方式：一种是通过 IDE 内的图形化界面，这种方式比较直观；另一种是直接编辑本地的配置文件，适合喜欢命令行操作或进行批量配置的场景。

方案一：通过 IDE 设置界面修改（推荐）

这是最常用且便捷的修改方式。

1. 进入设置

打开 Trae IDE，点击界面右上角的设置图标，然后选择「对话流」部分。

2. 定位命令运行模式

在”对话流”设置中，你会看到一个名为「自动运行命令」或「命令运行方式」的区域。你需要将模式从”始终手动运行”（默认）切换为「使用白名单」。

3. 编辑白名单列表

模式切换后，下方会出现一个名为「白名单作用于 IDE」的输入框。在这里，你可以按需添加、编辑或删除命令前缀。

4. 白名单匹配规则

当 Trae AI 执行命令时，只要命令的开头部分与你列表中的任意一个命令前缀匹配，该命令就会被自动执行，无需二次确认。例如，添加了 npm run，那么 npm run dev 和 npm run build 都会自动运行。

方案二：通过配置文件修改

此方式适合期望将配置纳入版本控制或进行自动化管理的开发者。

1. 定位配置文件

Trae 的配置主要位于项目级和用户级两个目录中：

配置级别 文件路径 适用场景
项目级（推荐） 项目根目录 .trae/settings.json 团队共享，建议提交到 Git
用户级 ~/.trae/settings.json 个人全局偏好设置

2. 编辑配置文件

用代码编辑器打开 settings.json，找到与”自动运行命令”和白名单相关的字段进行修改。如果字段不存在，可按以下格式手动添加：

各字段说明：

  • autoRunMode：设置为 "whitelist"，启用白名单模式
  • whitelistedCommands：数组类型，用于存放命令前缀字符串

补充说明

安全意识

白名单方便，但也降低了安全门槛。添加前请再三确认该命令或脚本是安全可信的，建议只添加那些你非常信任且操作行为确定的命令。

所有命令自动运行

Trae 也提供了一个”始终自动运行”模式，但这会完全禁用安全检查，出于安全考虑，在任何情况下都不建议轻易开启。

规则文件的区别

文件 用途
.trae/settings.json 管理 AI 的运行时行为设置（如命令权限）
user_rules.md 等规则文件 定义 AI 在生成代码时遵循的规范

它们是两个完全不同的配置体系，切勿混淆。
