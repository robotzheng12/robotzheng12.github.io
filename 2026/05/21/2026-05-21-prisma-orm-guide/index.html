Prisma 是新一代 Node.js/TypeScript ORM，通过声明式 Schema 定义数据模型，自动生成类型安全的查询客户端。本文从安装初始化到高级用法，全面讲解 Prisma 的核心操作。

二、常用命令速查

命令 说明
npx prisma init 初始化，生成 prisma 文件夹
npx prisma migrate dev --name init 开发环境迁移，生成并执行 SQL
npx prisma db push 暴力同步，直接覆盖数据库结构（危险）
npx prisma db pull 从数据库反向生成 Schema
npx prisma generate 生成 Prisma Client

2.1 prisma migrate dev 详解

这是开发环境中用于初始化或更新数据库结构的核心命令，按顺序完成以下 4 个关键操作：

  1. 差异检测 — 对比 schema.prisma 和数据库实际结构，生成 SQL
  2. 创建迁移文件 — 将生成的 SQL 保存为 migration.sql 文件，纳入 Git 版本控制，方便团队协作
  3. 连接数据库 — 执行上一步生成的 SQL
  4. 自动生成 Client — 迁移成功后自动运行 prisma generate

2.2 prisma db push ⚠️ 危险命令

暴力同步命令，不生成迁移文件，直接强制将数据库结构覆盖，并清空数据。仅在原型开发阶段使用。

2.3 prisma db pull 反向工程

连接数据库，读取所有表、字段类型、默认值以及外键约束，自动生成 schema.prisma 文件。适合从已有数据库逆向生成模型。

4.1 模块化拆分，告别单文件地狱

当项目超过 10 张表时，把所有 Model 写在一个 schema.prisma 里会让查找和修改变得极其痛苦。Prisma 原生支持将 Schema 拆分成多个文件。

4.2 抽象复用，消灭重复字段

在 TypeORM 中可以通过 BaseEntity 继承通用字段，但 Prisma 原生 Schema 不支持继承或抽象模型。手动在每个 Model 里复制粘贴 createdAt、updatedAt 不仅繁琐，还容易漏写。

解决方案：使用 ZenStack 增强层

ZenStack 是一个与 Prisma 完全兼容的开源工具，允许定义 abstract model，在编译时自动展开为标准 Prisma Schema。
